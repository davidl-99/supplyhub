El archivo __init__.py le indica a Python que la carpeta app puede tratarse 
como un paquete de Python.

El archivo apps/api/requirements.txt registra las dependencias instaladas 
y sus versiones.

.env.example es un archivo documenta las variables que necesita el proyecto, 
pero no contiene la contraseña real.

Docker Compose lee automáticamente el archivo .env ubicado junto a compose.yaml 
y utiliza sus valores para reemplazar expresiones como ${POSTGRES_DB}. El archivo 
.env no debe subirse porque puede contener credenciales

¿Qué es una migración?
Una migración es un archivo que describe un cambio en la estructura de la base de datos.

en la ruta apps/api/tests/conftest.py cada prueba:
1. Abre una conexión.
2. Inicia una transacción externa.
3. Ejecuta peticiones reales contra FastAPI.
4. Permite que el servicio llame a commit().
5. Revierte todos los cambios al terminar.
